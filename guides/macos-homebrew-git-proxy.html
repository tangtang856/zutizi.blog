一、详细分步实操流程

一、单独为 Git 配置代理

针对 github.com 独立配置代理：git config --global http.https://github.com.proxy http://127.0.0.1:7890

二、配置 Homebrew 环境变量

在 ~/.zprofile 中注入 export HOMEBREW_BOTTLE_DOMAIN 与 brew 代理命令。

三、验证克隆速度
