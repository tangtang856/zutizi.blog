Windows电脑客户端配置教程 - Clash Verge Rev极简指南

更新时间：2026年11月26日 适用系统：Windows 10 / Windows 11 推荐客户端：Clash Verge Rev (开源免费)

在Windows系统上，原版Clash for Windows停更后，Clash Verge Rev已成为目前最稳定、界面现代且开源可信的主流客户端。本教程手把手教你5分钟完成安装与订阅配置。

步骤一：下载与安装客户端

前往官方开源GitHub仓库下载最新安装包（通常为 .msi 或 .exe 格式）。双击运行并按照提示完成安装。

步骤二：获取并导入机场订阅

  1. 登录您购买的翻墙机场后台（如 飞鸟云 或 宽带公社）；
  2. 在仪表盘中找到'一键导入订阅'或复制'Clash订阅链接'；
  3. 打开 Clash Verge Rev，点击左侧菜单栏的 '订阅'（Profiles）；
  4. 在上方输入框中粘贴复制的订阅URL，点击右侧的 '导入'（Import） 按钮；
  5. 导入成功后，鼠标左键点击该订阅配置项使其高亮生效。

步骤三：开启系统代理与节点选择

  1. 点击左侧 '代理'（Proxies），模式务必选择 '规则'（Rule）；
  2. 在策略组中点击展开，挑选延迟较低的节点（如香港、日本或新加坡）；
  3. 点击左侧 '设置'（Settings），打开 '系统代理'（System Proxy） 开关；
  4. 此时打开浏览器访问 Google 或 YouTube，即可顺畅翻墙。

Windows常见问题与故障排查

⚠️ 电脑断网但QQ能上的情况如何解决？

这是因为关闭Clash时没有正常退出系统代理设置。解决办法：重新打开Clash并关闭'系统代理'，或者在Windows系统'设置' -> '网络和Internet' -> '代理'中手动关闭'使用代理服务器'。
