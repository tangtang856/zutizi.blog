Mac 终端 Terminal 配置代理命令加速开发环境实战

适用平台：macOS Terminal / iTerm2 更新日期：2026年11月26日 阅读耗时：约 5 分钟 编写：租梯子技术组
💡 教程导读与核心要点

开发人员经常遇到终端中 git clone 龟速或 curl 超时的窘境。这是因为终端默认不走系统 HTTP 代理，需通过环境变量明确声明代理通道。

一、详细分步实操流程

一、编辑用户 Shell 配置文件

打开终端，执行 nano ~/.zshrc 编辑当前用户的 zsh 配置文件。

二、添加代理快速开关别名

在文件末尾追加以下代码： alias setproxy="export https_proxy=http://127.0.0.1:7890 http_proxy=http://127.0.0.1:7890 all_proxy=socks5://127.0.0.1:7890; echo 'Proxy on'" alias unsetproxy="unset https_proxy http_proxy all_proxy; echo 'Proxy off'"

三、保存并重新加载配置

保存退出后执行 source ~/.zshrc 使其即刻生效。

四、测试终端代理

输入 setproxy 开启，随后执行 curl -I https://github.com，响应为 200/301 即表示开发终端翻墙提速成功。
