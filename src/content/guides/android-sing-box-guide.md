## 一、详细分步实操流程

      
        
          一、获取安装 APK
          前往 GitHub 官方 Releases 或 Google Play 下载并安装最新版 Sing-box APK。
        
      
        
          二、添加订阅 Profile
          打开应用 -> 进入 Profiles 页面 -> 点击右上角 '+' -> 形式选择 Remote -> 粘贴机场订阅链接并启用自动更新周期。
        
      
        
          三、选择出站模式与节点
          切换到 Dashboard，勾选刚刚添加的配置，在 Groups 策略组中挑选延迟较低的香港或日本节点。
        
      
        
          四、建立 VPN 连接
          点击右下角运行按钮，在系统弹窗中允许建立 VPN 连接即可畅享海外网络。
