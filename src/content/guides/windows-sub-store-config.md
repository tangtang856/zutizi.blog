💡 教程导读与核心要点
        
当您同时持有主力与备用多家机场节点时，手动切换极为繁琐。Sub-Store 是一款强大的高级订阅转换与过滤管理工具，支持一键合并、正则筛选与分流规则注入。

      

      
## 一、详细分步实操流程

      
        
          一、部署 Sub-Store 服务端或使用 Web 托管
          通过 Node.js 本地运行 npx sub-store 或访问受信的 Web 控制台添加本地工作区。
        
      
        
          二、导入多家机场原始订阅
          在 'Subscriptions' 界面点击添加，录入您的主力专线机场与备用机场链接，命名后拉取。
        
      
        
          三、设置组合订阅(Collections)与过滤规则
          创建组合订阅，利用正则表达式添加过滤规则（如过滤掉高倍率节点或离线节点），并设置节点前缀统一命名规范。
        
      
        
          四、输出统一订阅链接至客户端
          生成专属目标链接并导出为 Clash 或 Sing-box 格式，直接导入客户端即可享受一体化自动更新。
