💡 教程导读与核心要点
        
玩 PS5 港服/美服商城下载慢，或者 Switch 联机《马里奥赛车》《喷射战士》频繁掉线？只要局域网内有一台开着 Clash 的电脑，就能零成本为主机提供加速通道。

      

      
## 一、详细分步实操流程

      
        
          一、电脑端开启'允许局域网连接(Allow LAN)'
          在电脑上的 Clash Verge 中，打开'允许来自局域网的连接(Allow LAN)'开关，记录当前电脑的局域网 IP（如 192.168.1.50）与端口（7890）。
        
      
        
          二、在游戏主机上配置网络代理
          进入 PS5 / Switch 网络设置 -> 选择当前 Wi-Fi -> 高级设置 -> 将'代理服务器(Proxy)'从关闭改为使用。
        
      
        
          三、输入电脑的 IP 与端口
          代理服务器填入电脑的局域网 IP (192.168.1.50)，端口填入 7890，保存连接。
        
      
        
          四、测试网络连接
          在主机上测试网络，NAT 类型将由 NAT D/C 跃升为 NAT A/B，商城与游戏联机下载提速数十倍。
