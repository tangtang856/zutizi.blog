💡 教程导读与核心要点
        
v2rayNG 具有极简的操作界面与强大的分应用代理功能，能够随心指定只有 YouTube、Telegram、X 走代理，微信和国内银行保持完全直连。

      

      
## 一、详细分步实操流程

      
        
          一、添加订阅设置
          打开 v2rayNG -> 点击左侧侧边栏 -> '订阅设置' -> 点击右上角 '+' -> 粘贴机场提供的 v2ray 订阅 URL 并保存。
        
      
        
          二、更新并测速节点
          返回主界面，点击右上角三点菜单 -> '更新订阅'。节点全部展示后，点击三点菜单选择'测试全部真实连接'。
        
      
        
          三、设置分应用代理
          侧边栏进入'设置' -> 勾选'分应用代理模式' -> 勾选需要走梯子的海外 App，未勾选的国内应用将彻底不受任何代理干扰。
        
      
        
          四、启动服务
          选中延迟优秀的节点，点击右下角'V'字圆圈图标开启连接。
