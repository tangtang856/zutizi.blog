💡 教程导读与核心要点
        
Surfboard（俗称冲浪板）因其UI高度对标Surge而备受好评。它内存占用极小、面板图表极其美观，是追求质感体验的安卓用户的优秀选择。

      

      
## 一、详细分步实操流程

      
        
          一、安装 Surfboard
          通过 Google Play 商店或官方 GitHub 渠道安装 Surfboard 最新稳定版。
        
      
        
          二、通过链接添加配置 Profile
          进入 Config 选项卡 -> 点击右下角 '+' 号 -> 选择 'Download from Web' -> 粘贴机场托管订阅地址下载配置。
        
      
        
          三、节点分组与延迟探测
          在 Proxies 界面切换策略组，长按节点可发起即时延迟 Ping 测速。
        
      
        
          四、开启连接与监控仪表盘
          点击下方中央圆形开关启动，在 Dashboard 界面可直观查看实时上传下载流量图表与分流日志。
